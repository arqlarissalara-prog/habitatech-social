# 🏠 HabitaTech — Automação Orçamentária e Diagnóstico Habitacional Social

O **HabitaTech** é uma ferramenta open-source em Python desenvolvida para otimizar o dimensionamento de materiais e estimativa de custos para reformas de moradias de interesse social. 

## 🎯 Propósito Social
Garantir que projetos de assistência técnica habitacional para populações vulneráveis possam ser orçados com agilidade, precisão e baixo custo, unindo conhecimentos de Arquitetura, Contabilidade e Ciência da Computação.

## 🛠️ Tecnologias Utilizadas
- **Python 3.x**
- **Git & GitHub** (Versionamento de código)
